# 电商品牌视觉素材工作室 2.0 产品需求文档

**全球品牌活动与多语言素材运营**
需求评审版 · 2026-11-26 · 计划基线 v1.1.0（b8585de）

## 产品目标与交付边界

当前发行覆盖商品图候选、品牌审校、采用与素材包。本版支持以下业务流程。品牌总部冻结一套活动主创意，地区团队本地化文案与版式，逐区域审校授权，上线后跟踪撤稿和替换。 [项目说明](../../README.md) · [上一版业务需求](02-业务与交互-prd.md)

验收素材使用有再分发许可的字体和原创商品图。支付型图像接口为可选连接器，本地翻译和排版可走完整案例。

## 使用者与工作台

总部创意负责人锁母版，地区审校批准文案，版权负责人授权，投放运营发布与撤稿。

地区工作台并排呈现母版与译稿，标出行宽、阅读方向和产品保护区。权利面板解释哪些地域可投及到期时刻，撤稿页显示每个渠道的回执。

| 关联需求 | 角色与入口 | 操作细节 | 需要读回的字段 |

| R2 · 术语与翻译 | 地区审校/译稿对照 | 逐段审校术语、禁用词与免责声明并记录理由 | segment_rev、review_decision |

冻结母版、字体、地区术语、授权和渲染器版本。人工验收标注遗漏字形、商品翻转和安全区遮挡，未解决的阻断项对应的发布成功数必须为零。

## 状态、权限与数据

地区稿 待翻译→待排版→待审校→可交付→已在线→撤回中或已替代，母版修订需再评估相关地区。

地区与语种分别建模。即使使用同一种语言也须按投放地域独立校验权利，导出时再校验一次。

MySQL 保存业务记录与操作回执。下列为新增逻辑对象和关键字段，所有归属组织的数据都须持有可校验的组织标识。

- `campaign(master_rev,region)`
- `copy_segment(source_hash,locale)`
- `localization(term_rev,approval)`
- `rights_grant(asset,territory,expires)`
- `placement(channel,asset_rev,receipt)`

交付键由活动修订、地域、语言和渠道组成，权利撤销按素材版本反查所有关联版位。 写入前校验操作者对目标对象的权限与当前修订。详情、搜索、导出和后台重试按同一归属校验。保留决定者、请求号、前后状态、发生时间及关联证据编号。

## 核心接口与集成

主要写入入口为 `POST /campaigns/{id}/placements`。请求必填字段为 `locale, territory, channel, asset_rev, rights_rev`。成功回执提供 placement_id, manifest_digest, delivery_state。请求另带租户身份和幂等键。相同键及相同内容返回原业务编号，相同键对应不同内容返回 409。输入不满足业务约束时返回 422 和字段路径，身份无权限读取的跨租户对象返回 404。

需要异步处理时，接收事务同时写入业务记录与待处理事件，再返回 202 及回执查询地址。回读须显示当前状态、已完成步骤、上次失败原因和可重试条件。外部系统已受理但应答丢失时，按原请求身份核查实际结果。

### 合成请求与业务回执样例

请求体示例使用演练环境中的对象。带摘要的样例在开发验收时应替换为实际文件或参数的计算值。

```json
{
  "locale": "ar",
  "territory": "AE",
  "channel": "catalog",
  "asset_rev": "A4",
  "rights_rev": "G2"
}
```

业务回执示例可由提交响应或后续状态查询取得。

```json
{
  "placement_id": "P4",
  "manifest_digest": "sha256:eeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee",
  "delivery_state": "pending"
}
```

授权不足以覆盖排期末日时返回 422，指出受限地域、缺口日期和需替换的源素材。

## 升级、部署与恢复

已有采用图作为可追溯主素材导入，缺地区权利声明时只允许内部预览，补齐后才可发布。 在隔离副本运行迁移预检，输出记录数量、归属冲突和待处理编号。新增结构先部署，回填分批提交并保存游标，完成对账后按租户启用新入口。

演练时在首次成功写入新业务后中断进程，从检查点重启。核对地区授权证明、像素摘要及外部上架回执。需要退出试点时停收新请求，排空已受理操作并导出未决清单。涉及数据恢复时同时恢复数据库与关联证据，再核对外部已生效的动作。

## 编号验收用例

以下均为下一版待执行的验收条件。正常与异常场景使用隔离租户、固定时钟和可重置的合成数据。

| 编号 | 需求 | 操作与可观察结果 |
| --- | --- | --- |
| A1 | R1 · 活动母版 | 地区替换背景后商品图层摘要保持一致。 |
| A2 | R1 · 活动母版 | 越权修改品牌标识图层时阻止送审。 |
| A3 | R2 · 术语与翻译 | 新输入文案通过真实本地模型出稿，审校员可逐句修改。 |
| A4 | R2 · 术语与翻译 | 禁用词或缺强制免责声明时不能通过审核。 |
| A5 | R3 · 本地化排版 | 阿拉伯语右起排版且商品图案方向正确。 |
| A6 | R3 · 本地化排版 | 缺字或文字超过安全区时按语种标注失败。 |
| A7 | R4 · 地区权利 | 只授权 A 区的图在 B 区只能替换后送审。 |
| A8 | R4 · 地区权利 | 排期跨越授权到期日时显示冲突日期。 |
| A9 | R5 · 投放交付 | 四渠道中三个成功时只补第四个。 |
| A10 | R5 · 投放交付 | 供应商超时先查发布编号，防止重复上架。 |
| A11 | R6 · 撤稿与改版 | 下架一个源图只影响引用它的 6 个版位。 |
| A12 | R6 · 撤稿与改版 | 一个渠道未回执时活动保持部分撤回并列明负责人。 |
| A13 | 全流程 | 冻结 3 地区×2 语言×2 渠道共 12 个版位，实跑本地模型出译稿，逐项记录强制术语命中、溢出、审校修改量与成本来源。 |
| A14 | 容量与可靠性 | 20 地区、5 语种、4 渠道生成 400 个投放位，失效授权命中的投放位召回清单 ≤ 15 秒生成。 |

负载报告须记录机器及依赖版本、预热和采样时长、成功数、拒绝数和超时数。验收人从工作台与业务记录两侧核对 A13，并附上原始输入、回执和最终状态。真实模型、人工判断和回放夹具分别出具结果，记录模型及权重版本、输入规模、失败样本与资源消耗。

### A13 本地化评测

在 12 个版位样例中预置两处禁用词、一处字体缺字和一处地区许可过期。四处均须被发布门槛拦截，修订审批后仅重新交付受影响版位。

## 分期交付

1. **母版与术语。** 交付可导入的样例和可读回的第一批业务对象，验证基础身份、归属及版本。
2. **地区排版及权利审校。** 串通参与角色和执行入口，演练并发、重复请求及部分成功后的恢复。
3. **渠道投放和撤稿。** 完成全流程验收、容量实测和旧版升级。随开源发行提供中文配置、样例输入输出、备份恢复步骤及已知限制。
