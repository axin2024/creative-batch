# 电商品牌视觉素材工作室｜开源项目说明与首个案例

**creative-batch** 是面向自托管的 PHP 项目。PHP 管工作台与作业，图像生成交给可替换后端；原创商品图和模板支持本地演示。 本页作为后续公开使用手册的需求稿，实际发行时补入测试版本、安装入口与已验证的依赖组合。

## 准备

原创商品、合成标识、三套渠道规格与离线结果包。

一款新品有红蓝两色、三个画幅，各生成两份候选共 12 张；其中一张包装文字错误，一张缺商用授权。

## 第一次使用

1. 登记新品红蓝两款、三种渠道画幅及品牌母版，核对授权到期时间。
2. 生成 12 个候选任务，核对报价，先用离线样例审阅，再对新增商品执行真实模型试作。
3. 退回包装文字错误候选，给缺权候选标记阻断；为六个组合各选一张批准图。
4. 发布后逐项检查尺寸、摘要、授权和选片理由，随后撤销一项权利并检查受影响包列表。

## 对照综合样例

错误候选退回，缺权素材阻断交付。每颜色每渠道各采用一张，共六项交付，清单有商品、模板、输入及采用理由。 对照结果时保留源记录号、版本和操作时间，追踪从输入到最终交付的关联。

## 制造一次可恢复的异常

低信心识别须显示原图对照并转人审。回到对象详情核对 quality_check 和审计记录，再按指定版本恢复或重试。确认相同操作不会生成两份有效结果。

## 自托管与反馈

外部生成超时须查原任务，按作业汇总预估与实付；授权撤回后阻止新下载并列出受影响包。 提交问题请提供版本、最小合成输入、预期与实际结果。对接扩展可从以下方向开始：图像工作流、渠道规格与品牌规则；公开素材逐项登记来源、版权和使用范围。
