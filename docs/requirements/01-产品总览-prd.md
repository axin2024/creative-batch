# 电商品牌视觉素材工作室｜产品总览

**正式需求基线 v2 · PHP · 独立开源项目**

PHP 管工作台与作业，图像生成交给可替换后端；原创商品图和模板支持本地演示。

## 使用者与责任边界

品牌管理员维护规范，美术选模板，运营提交批次，审核员核查商品保真与授权，渠道人员取用获准版本。

## 完整交付链路

商品与品牌 → 模板与规格 → 批量计划 → 模型生成 → 质量与品牌审核 → 版本与采用 → 交付与授权 → 生产运营。

## 产品范围与里程碑

| 里程碑 | 能力 | 交付物或判断依据 |
|---|---|---|
| 基础数据与首笔业务 | 商品与品牌、模板与规格 | 同一商品按主图、竖图、横幅分别布局。 |
| 贯通核心生产流程 | 批量计划、模型生成、质量与品牌审核 | 人工识别包装字错后该图禁止采用。 |
| 异常、运营与独立交付 | 版本与采用、交付与授权、生产运营 | 运营可解释每张采用图分摊的候选成本。 |

里程碑用于排开发顺序。首个完整公开版包含本项目全部 8 个业务域、24 项细分能力以及验收表的全部编号场景。

## 公开演示与成效

一款新品有红蓝两色、三个画幅，各生成两份候选共 12 张；其中一张包装文字错误，一张缺商用授权。

错误候选退回，缺权素材阻断交付。每颜色每渠道各采用一张，共六项交付，清单有商品、模板、输入及采用理由。

固定 12 张夹具验证六种规格，尺寸不合格和授权不足的导出数量为零；真实生成另记录用时与人工通过率。以上为发布目标，验收报告须给出实测环境及原始记录。

## 边界与外部依据

外部生成超时须查原任务，按作业汇总预估与实付；授权撤回后阻止新下载并列出受影响包。

接口和业务术语的参考材料见 [ComfyUI 文档](https://docs.comfy.org/)。具体范围由本项目的操作契约与验收用例界定。
