# 电商品牌视觉素材工作室｜状态与操作契约

## 素材批次的生命周期

草案→规格冻结→生成→候选复核→逐渠道采用→发布。返工生成新候选并关联原问题。

## 权限与操作者

品牌管理员维护规范，美术选模板，运营提交批次，审核员核查商品保真与授权，渠道人员取用获准版本。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 提交商品、画幅、模板版和可用授权，先输出任务数量与费用估计，确认后才能提交真实生成。
2. 导出按商品、颜色、渠道及活动期检查唯一采用项、授权有效期和尺寸，返回包与逐项清单。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 商品与品牌 | 每个商品色款绑定原始图、不可变包装元素、色板与授权范围，品牌方审批母版。 | 授权已过期的图片不能进入公开批次。 |
| 模板与规格 | 模板声明商品遮罩、文案域、留白、分辨率与字体资源；渠道变更规格不回写旧批次。 | 错误宽高比提示正确像素值。 |
| 批量计划 | 按变体、规格、候选数展开，先给总量和费用上界，运营确认后冻结输入。 | 重复点击提交不再发起第二组真实任务。 |
| 模型生成 | 模板固定模型、参数与种子可用性，生成结果携费用及来源；结果未知先查单。 | 供应商已受理但超时不能整批重新提交。 |
| 质量与品牌审核 | 自动规则与人审分开，颜色、包装文字、变形、背景及标识逐项记录原因，候选可被退回。 | 低信心识别须显示原图对照并转人审。 |
| 版本与采用 | 每个活动、色款、渠道版本最多一份有效采用，改选只影响相关输出，历史包留摘要。 | 并发采用不能产生两张活动主图。 |
| 交付与授权 | 导出前逐项验尺寸、审核、授权期限和渠道。撤回授权后列出已交接包及其领取人。 | 缺一个采用项时只能生成标记缺项的预览。 |
| 生产运营 | 比较后端产出、人工采纳与返工原因，按商品隔离评测，避免相同近似图跨训练与验证。 | 回放样例不计入真实生成费用。 |

## 失联、中断及恢复

批次按商品、画幅和变体冻结输入摘要，供应商任务只登记一次；发布时验证采用项与授权快照。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

外部生成超时须查原任务，按作业汇总预估与实付；授权撤回后阻止新下载并列出受影响包。 错误候选退回，缺权素材阻断交付。每颜色每渠道各采用一张，共六项交付，清单有商品、模板、输入及采用理由。
